# Mitwirken

1. Einen Branch vom aktuellen Hauptzweig erstellen.
2. Die bestehende Beta-Excelstruktur nicht verändern.
3. Objektordner-Beziehungen ausschließlich über die zentrale Validierung verwenden.
4. Vor einem Commit `python -m py_compile main.py` ausführen.
5. Keine produktiven Daten, Backups oder Build-Artefakte committen.
6. Änderungen im `CHANGELOG.md` dokumentieren.
