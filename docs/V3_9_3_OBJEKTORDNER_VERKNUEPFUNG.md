# Version 3.9.3 – Objektordner-Verknüpfung und Dashboard-Volltextsuche

## Neu
- Objektordner-Auswahl oberhalb jeder Tabellenansicht.
- Bestehende Tabellen werden über vorhandene Spaltenköpfe verbunden.
- Verknüpfung über Objektordner, Objekt, Objektname, Wohnung, Mieter, Vermieter und Ort.
- Dashboard-Suche über alle Schlagwörter in allen Tabellen.
- Dashboard kann zusätzlich nach Objektordner gefiltert werden.
- Doppelklick auf einen Dashboard-Treffer öffnet den zugehörigen Bereich.

## Wichtig
- Keine bestehende XLSX-Datei wurde verändert.
- Keine Spalte wurde ergänzt, gelöscht oder umsortiert.
- Die Beta-Excelstruktur bleibt vollständig kompatibel.
