# Version 3.4.1 – Kontoauszug PDF-Import

## Neu
- PDF-Kontoauszüge einlesen
- Text aus PDF extrahieren
- Buchungen automatisch erkennen
- Mieteinnahmen automatisch erkennen
- Mieter zuordnen
- erkannte Mieten in `Zahlungen` übernehmen

## Zusätzlich
- CSV-Import bleibt erhalten
- Beispiel-PDF enthalten, sofern erzeugbar

## Wichtig
Der PDF-Import funktioniert mit Text-PDFs. Reine Scan-PDFs ohne Text benötigen OCR und werden nicht automatisch gelesen.
