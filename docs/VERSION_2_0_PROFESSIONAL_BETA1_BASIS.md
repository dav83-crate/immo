# ImmoVerwaltung 2.0 Professional – Beta‑1‑Basis

## Grundlage
Diese Version wurde direkt auf Basis der hochgeladenen Beta‑1‑ZIP erstellt.

## Wichtig
- Beta‑1‑Daten bleiben im Ordner `daten/` erhalten.
- Excel-Dateien wurden nicht verändert.
- `config.json` verweist auf den lokalen Ordner `daten`.
- Die moderne Oberfläche und Analysefunktionen sind eingebaut.

## Start
`STARTEN.bat` ausführen oder:

```bash
python main.py
```

## EXE
`EXE_ERSTELLEN.bat` ausführen.
Die EXE wird auf dem Desktop erstellt.
