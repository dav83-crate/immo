# V50 Gesamtversion mit Optik und Animation

## Enthalten
Diese Version basiert auf V49 ohne Beispieldaten und enthält alle bisherigen Aktualisierungen.

## Optische Verfeinerungen
- hellere linke Seitenleiste
- bessere Lesbarkeit der Navigation
- aktiver Menüpunkt wird hervorgehoben
- bessere Tab-Optik
- größere Seitenleiste
- modernere Abstände

## Animation
Beim Wechsel über die linke Seitenleiste wird der Inhaltsbereich weich eingeblendet.

## Daten
Keine Beispieldaten enthalten.
Die Excel-Struktur bleibt unverändert.
