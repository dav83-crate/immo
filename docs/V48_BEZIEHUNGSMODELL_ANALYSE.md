# V48 Beziehungsmodell und Analyse-Center

## Grundsatz
Die Excel-Struktur bleibt unverändert.

## Neue Funktion
Das Analyse-Center verbindet Tabellen im Hintergrund über gleiche Tabellenköpfe.

Beispiel:
- Mieter ↔ Mieter
- Objekt ↔ Objekt
- Wohnung ↔ Wohnung
- Status ↔ Status
- Objektordner ↔ Objektordner
- Wohnungsordner ↔ Wohnungsordner

## Bedienung
1. Dashboard öffnen.
2. `Analyse-Center` anklicken.
3. Beziehungsfeld auswählen oder `Freie Suche` verwenden.
4. Suchwert eingeben.
5. Treffer werden aus allen Tabellen gesammelt angezeigt.

## Export
Die Treffer können als Excel-Datei exportiert werden.

## Wichtig
Es werden keine bestehenden Excel-Dateien verändert.
Die Analyse liest nur Daten.
