# Version 2.0.8 – BK-Automatisierung

## Neu
Ein eigenes Modul `BK-Automatik` wurde ergänzt.

## Funktionen
- Betriebskosten aus aktuellem Datenstand berechnen
- BK-Vorauszahlung je Mieter gegen Ist-BK rechnen
- Nachzahlung oder Guthaben automatisch ausweisen
- Jahresvordruck je Mieter erzeugen
- Vordruck drucken
- alle Vordrucke als HTML exportieren
- Excel-Export der Abrechnung

## Datenquellen
- Mieter
- Betriebskosten
- Zahlungen

## Wichtig
- Keine bestehende Excel-Struktur wurde verändert.
- Die Berechnung arbeitet lesend mit dem aktuellen Datenstand.
- Vordrucke sollten vor Versand geprüft werden.
