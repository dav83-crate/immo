# Version 6.0 – Enterprise Foundation

## Neue Hauptmodule
- Enterprise Objekt 360° mit Stammdaten, Vermietung, Finanzen, Aufgaben, Schäden, Dokumenten und Timeline.
- Dokumenten-Center 2.0 mit zentralem Dokumentindex, Volltextfilter und Pfadprüfung.
- Workflow-Regeln PRO mit Vorschlägen für offene Rechnungen, Schäden, Fristen und Plausibilitätsprobleme.
- Workflow-Vorschläge können kontrolliert in die vorhandene Aufgaben-Tabelle übernommen werden.

## Architektur
- Keine bestehende Excelstruktur geändert.
- Keine Spalten ergänzt, gelöscht oder umsortiert.
- Objektordner-Validierung bleibt die zentrale Beziehung.
- Rollen, Rechte, Modern UI und EXE-Ressourcen bleiben erhalten.
