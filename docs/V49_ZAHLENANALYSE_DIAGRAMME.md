# V49 Zahlenanalyse und Diagramme

## Neu
Die Analyse wurde um eine echte Zahlenverwertung ergänzt.

## Funktionen
- erkennt numerische Tabellenfelder automatisch
- berechnet Anzahl, Summe, Durchschnitt, Minimum und Maximum
- zeigt die Top-Zahlenfelder als Balkendiagramm
- Export der Zahlenanalyse nach Excel

## Beispiele für erkannte Felder
- Miete
- Kaltmiete
- Betrag
- Kosten
- Beitrag
- BK monatlich
- BK jährlich
- Ist-BK jährlich
- Nachzahlung
- Guthaben
- Wohnfläche
- Stunden

## Wichtig
Die Excel-Struktur wird nicht verändert.
Alle Analysen lesen nur vorhandene Daten.
