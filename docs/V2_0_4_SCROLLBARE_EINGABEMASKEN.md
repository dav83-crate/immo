# Version 2.0.4 – Scrollbare Eingabemasken

## Neu
Alle Eingabemasken wurden scrollbar gemacht.

## Verbesserungen
- Vertikaler Scrollbereich in Neu-/Bearbeiten-Dialogen
- Mausrad funktioniert
- Größeres Dialogfenster
- Felder werden automatisch gruppiert:
  - Allgemein
  - Vertrag / Versorger
  - Finanzen / Fristen
  - Dokumente / PDF
  - Ordner / Ablage
  - Notizen

## Wichtig
Die Excel-Struktur wurde nicht verändert.
Bestehende Beta‑1‑Daten bleiben erhalten.
