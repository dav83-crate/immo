# V48.2 Analyse testen

## Analyse-Center finden
Das Analyse-Center ist jetzt an zwei Stellen erreichbar:

1. Links im Menü: `Analyse-Center`
2. Oben rechts: Button `Analyse-Center`

## Beispieldaten
In den Excel-Dateien sind Beispieldaten enthalten, falls die Tabellen leer waren.

Teste z. B.:

- Freie Suche: `Max Mustermann`
- Freie Suche: `Musterstraße 10`
- Beziehungsfeld `Mieter`: `Max Mustermann`
- Beziehungsfeld `Objekt`: `Musterstraße 10`

## Export
Im Analyse-Center:
1. Suche ausführen.
2. `Excel exportieren` anklicken.
3. Speicherort wählen.
4. Nach dem Export öffnet sich der Zielordner.
