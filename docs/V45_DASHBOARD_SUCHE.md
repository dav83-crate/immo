# V45 Dashboard-Suche

## Neu
Vom Dashboard aus kann nach folgenden Daten gesucht werden:

- Mieter
- Vermieter
- Objekt
- Alle

## Ergebnis
Die Suche zeigt alle passenden Treffer aus allen Tabellen gesammelt an.

Spalten:
- Bereich
- Typ
- Treffer
- Zeile
- Inhalt

## Öffnen
Wenn ein Treffer eine PDF, einen Ordner oder einen Pfad enthält, kann dieser direkt geöffnet werden.
