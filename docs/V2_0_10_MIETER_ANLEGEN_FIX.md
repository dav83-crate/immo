# Version 2.0.10 – Mieter anlegen Fix

## Behoben
Beim Neuanlegen von Mietern konnte der neue Datensatz nicht sichtbar werden bzw. Felder konnten durch die neue gruppierte Eingabemaske unvollständig zurückgegeben werden.

## Änderung
- EingabeDialog gibt jetzt immer exakt so viele Werte zurück wie Tabellenfelder vorhanden sind.
- Nach Speichern wird die Tabelle neu aus Excel geladen.
- Mieter werden nach dem Anlegen direkt sichtbar.

## Wichtig
- Keine Excel-Strukturänderung.
- Seitenbutton-Schriftfarbe bleibt #f00000.
