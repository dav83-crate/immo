# Version 3.1 – Globale intelligente Suche

## Neu
Eine zentrale Suche über alle Datenbereiche.

## Suchbar
- Mieter
- Objekte
- Wohnungen
- Rechnungen
- Zahlungen
- Kundennummern
- Vertragsnummern
- Versorger
- Dokumente/PDF-Pfade
- Aufgaben, Fristen und Schäden

## Funktionen
- Trefferliste mit Bereich und Zeile
- Doppelklick/Bereich öffnen
- Schnellbuttons
- Excel-Export der Treffer

## Wichtig
- Keine Excel-Strukturänderung.
- Seitenbutton-Schriftfarbe bleibt #f00000.
