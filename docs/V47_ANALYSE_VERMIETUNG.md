# V47 Analyse Vermietung

## Neu
Vom Dashboard aus kann eine Vermietungsanalyse geöffnet werden.

## Auswertung
Die Analyse zeigt:

### Pro Objekt
- Gesamt
- Vermietet
- Frei
- Unklar
- Vermietungsquote

### Pro Vermieter
- Gesamt
- Vermietet
- Frei
- Unklar
- Vermietungsquote

## Grundlage
Die Auswertung nutzt:
- Tabelle `Wohnungen`
- Spalte `Objekt`
- Spalte `Status`
- Tabelle `Objekte`
- Spalte `Vermieter`

## Status-Erkennung
Als vermietet gelten u. a.:
- Vermietet
- Aktiv
- Belegt

Als frei gelten u. a.:
- Frei
- Leer
- Verfügbar
- Unvermietet
