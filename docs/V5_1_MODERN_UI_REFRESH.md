# Version 5.1 – Modern UI Refresh

## Optische Neuerungen
- vollständiges modernes Designsystem in Light und Dark.
- neue kompakte Kopfzeile mit globaler Suche.
- Benachrichtigungsanzeige mit Live-Anzahl.
- moderner Benutzerbereich in der Kopfzeile.
- Navigation in logische Gruppen sortiert.
- Navigation ein- und ausklappbar.
- weichere Karten, Tabellen, Tabs und Formulare.
- moderne Scrollleisten und Fokuszustände.
- dezente Seitenübergangsanimation.

## Neue Bedienfunktionen
- Strg+K fokussiert die globale Suche.
- Strg+Shift+P öffnet die Schnellaktionen.
- Suche direkt aus der Kopfzeile.
- Benachrichtigungsbutton öffnet den Verwaltungsleitstand.

## Wichtig
- keine Excelstruktur verändert.
- keine Spalten ergänzt, gelöscht oder umsortiert.
- Objektordner-Validierung bleibt aktiv.
- Rollen und Rechte bleiben aktiv.
- Navigationsschriftfarbe #f00000 bleibt erhalten.
