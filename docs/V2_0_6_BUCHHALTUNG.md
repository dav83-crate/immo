# Version 2.0.6 – Buchhaltungs-Unterprogramm

## Neu
Ein eigenes Unterprogramm `Buchhaltung` wurde ergänzt.

## Grundlage
Die Buchhaltung liest vorhandene Daten aus:
- Zahlungen
- Rechnungen
- Mieter

## Funktionen
- Einnahmen berechnen
- Ausgaben berechnen
- Saldo berechnen
- offene Posten listen
- Kostenarten summieren
- Jahr-/Monatsfilter
- Diagramm
- Excel-Export

## Wichtig
Die Excel-Struktur wurde nicht verändert.
Es wird nur aus vorhandenen Tabellen gerechnet.
