# V40 Mieterordner und BK-Rechner

## Mieter
Der Bereich `Mieter` wurde um folgende Spalten erweitert:

- BK monatlich
- BK jährlich
- Objektordner
- Wohnungsordner

## BK-Rechner
Über den Button `BK-Rechner` kann aus einer monatlichen Betriebskostenvorauszahlung eine Jahres-BK berechnet werden.

Formel:

BK jährlich = BK monatlich × Monate

Standardmäßig werden 12 Monate verwendet.

## Kompatibilität
Bestehende Betatest-Daten bleiben grundsätzlich kompatibel.
Neue Spalten werden hinten ergänzt.
