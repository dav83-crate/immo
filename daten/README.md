# Lokale Daten

Dieser Ordner enthält im produktiven Betrieb die Excel-Dateien der ImmoVerwaltung.

Aus Datenschutz- und Sicherheitsgründen werden produktive XLSX-Dateien **nicht in Git versioniert**. Die Anwendung legt fehlende Dateien anhand ihrer internen Schemata an oder bestehende Beta-Daten können lokal in diesen Ordner kopiert werden.

Vor einem Update sollte der komplette Ordner `daten/` gesichert werden.
